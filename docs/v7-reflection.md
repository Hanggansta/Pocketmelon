# v7 复盘：口袋瓜与 SOTY 级网站的差距

> 对标对象：Lusion v3（Awwwards 2023 年度网站）、Lando Norris / OFF+BRAND（2025 年度网站）、Messenger 与 Igloo Inc（abeto，2025 年度开发者奖 / 2024 年度网站）、Immersive Garden（2025 年度机构）、Garden Eight（东京）。
> 参考文献：Chu & Tai《MoXi: Real-Time Ink Dispersion in Absorbent Paper》（SIGGRAPH 2005）。

## 一、它们共同在做的事

| | 颜色 | 字体 | 首屏 | 交互 |
|---|---|---|---|---|
| Lusion v3 | 黑白，加一个蓝、一个荧光绿点缀 | 只用一款无衬线（Aeonik），标题 8–10vw，字距 −0.02em | 一个实时 3D 场景 | 鼠标直接驱动场景，有声音 |
| Lando Norris | 只有两个颜色：#D2FF00 加 #111112 | 粗体大字，一个强调色 | 一个头盔 | 滚动 + 手势，转场很利落 |
| Immersive Garden | 暖灰加近黑 | 衬线（PS Times）做标题，Helvetica 做功能文字 | 全屏 WebGL | 衬线文字缓入，自定义光标 |
| Garden Eight | 骨白、炭黑，加一个朱红（很少用） | 两款字，H1 约 15vw，像海报 | 粒子光标 | 拆字动画、跑马灯 |
| Messenger / Igloo | 材质本身就是颜色 | 克制 | 一个可玩的世界 | 简单操作，手感、音效、材质 |

归纳起来就是：**一屏只讲一件事；两三个颜色，外加一个很少出现的强调色；最多两款字体，标题按 vw 放到海报尺寸；交互真实可玩，材质有手感。**

## 二、我们差在哪里

1. **首屏太满。** v5/v6 的体素猫首屏里同时有猫、体素、爆散、四个角标、声音按钮、提示语、圆角卡片和两行标题，信息多，没有重点。顶级网站的首屏只有“一个主角 + 一行字”。
2. **水墨只是摆出来看的。** “品”字只播放一段书写动画，访客无事可做。它是插图，算不上体验。Lusion 和 abeto 的作品让人想伸手碰，我们的让人只是看看。
3. **一笔墨的质感不对。** 旧版是字体轮廓加噪声：
   - 没有纸的纤维，墨不会顺着纤维渗开（洇）；
   - 没有“水”这个变量，所以出不来墨边积墨、飞白和颗粒感；
   - 访客要先输入汉字，输入框本身就打断了沉浸感。
4. **字体太多，不够高级。** 原来同时用了 Fraunces、Geist、Pixelify、思源宋、思源黑和志莽行书。思源宋体排得再好也是“系统感”的宋体，缺一款有性格的中文标题字。标题字号偏小（约 6vw），不够海报感。
5. **版式像网页，不像杂志。** 没有竖排、没有落款印章、没有栏线与编号，网格在页面上看不出来。

## 三、v7 的改法

- **首屏：一张宣纸。**
  - 移动光标就是落笔，停留是蘸墨，点击会滴下一滴墨。
  - 开场只画一个圆相（ensō），一笔从浓到干，尾巴散成飞白。
  - 整屏只用墨黑、纸色和一枚朱砂印。
  - 文字按杂志开篇来排：顶栏三条事实，大标题，右侧竖排“墨分五色”和落款印。
- **墨的引擎（`src/modules/ink/fluid.js`，WebGL2）：** 参考 MoXi，分三层耦合。
  1. **流体速度场：** 笔会带动水，滴墨会把水向外推。
  2. **墨水场：** 记录湿颜料、水、已固着颜料和干后的水痕。纸的每一处只能吸住一定量的水，多出来的水才会顺着纤维渗出去，所以晕染会自己停下，边缘呈羽状。颜料跟着水走；水越干，颜料固着越快，干燥前沿积墨更多，形成墨边。
  3. **程序化宣纸：** 由云絮状纸浆、弯曲的长纤维和纸纹组成。它决定渗透率（洇）、干笔跳过纸面低处的位置（飞白）和颗粒感，并作为有起伏的表面打光。
  - **笔是有“毛”的：** 笔尖上有横向分布的笔毛纹理。走得越远墨越少，走得越快越细越干，停下就会重新蘸墨。
- **“品”改为“矾水显字”：** 整张纸先刷了矾，只有“品”字的位置没刷。访客用墨扫过纸面，矾面不吃墨，墨会浮起褪去，字就自己显出来。这正是传统的矾水显字技法，显字的过程也由访客亲手完成。
- **一笔墨：** 去掉输入框，只用鼠标。按住拖动就是书写，有焦、浓、重、淡、清五个墨色，可以“换一张纸”，轻点会滴墨。
- **字体：**
  - 中文标题用 **京華老宋体**，带铅字印刷的墨色与字口；
  - 中文正文用 **思源宋体**，像印刷书页；
  - 拉丁文标题用 **Instrument Serif**，字身窄，适合放到海报尺寸，并有斜体；
  - 功能文字保留 Geist / Geist Mono。
  - 首页去掉 three.js、体素场景和声音模块。

## 四、还没做的

- 墨的引擎还没按 GPU 分档（低端设备应降低分辨率与迭代次数）。
- 中文字体的 `@font-face` 样式表约 258 KB gz，虽然异步加载，仍可以按页面实际用字再裁一次。
- 京華老宋体的授权方声明可免费商用，正式上线前仍建议法务确认一次。
- 声音（磨墨、落笔）可以作为下一步，提升手感。
