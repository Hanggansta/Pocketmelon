# v8：推倒重做

## 为什么 v7 不合格

- **v7 的问题出在隐喻：** "一张纸，你在上面画"本质上是静态平面，没有镜头，没有时间线，也没有转场。Lusion 这一级别的站，首屏都是**被导演过的**：开场有节奏，有揭示，滚动是一段连续的镜头。
- **文字太多：** 顶部信息行、提示行、竖排、导语、按钮全挤在首屏，首屏没有呼吸。
- **实验室成了凑数：** 可变字体、瓜子阵、像素显影都只是小玩具，撑不起"实验室"三个字。

## v8 的原则

1. **首屏像片头。** 黑场、署名、字幕条开幕、一滴墨落水、墨聚成名，再开幕。整个开场只有一行字。
2. **墨是流体，不是纸。** 用的是墨在水里的真实流体：涡量约束、浮力和旋度噪声。字是被流场"吸"出来的，可以被搅散，散了还会再聚回来。
3. **滚动就是镜头。** 字溶解、镜头推近、墨淹满画面，然后直接切进下一幕的黑。
4. **实验室只放有技术含量的东西：**
   - GPU 粒子（13 万粒）；
   - 精确数学流纹（Jaffer–Lu）；
   - SDF 光线步进加次表面散射的玉石。
5. **删字。** 删掉了各区块的 meta、提示语、合作方案卡片和原则说明，只留标题和必要的一句话。

## 还没做

- GPU 分级：低端机目前只靠降分辨率。
- 声音。
- 中文字体 CSS 仍有 258 KB（gzip）。
- 京华老宋体的授权仍需确认。
